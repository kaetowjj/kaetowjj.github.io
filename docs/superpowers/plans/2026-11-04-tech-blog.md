# Tech Blog Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Native execution in this session follows the owner's explicit instruction to complete the merge with SVG icons.

**Goal:** One Tech Blog collection with shareable single-Tag filtering; preserve bilingual articles, Essays, Photography, Home personal copy and SVG link icons.
**Architecture:** Jekyll builds _tech articles, the archive and canonical Tag links. Small native JS filters existing DOM rows and coordinates URL/history. No client database or new dependency.
**Tech Stack:** Jekyll/Liquid, Markdown/YAML, CSS, native JS, Node tests, Playwright.
**Spec:** Owner's 2026-11-04 “Merge Engineering Notes & Projects into Tech Blog” and decorative Arrow Up Right requests, summarized below.

## Global constraints

- Navigation: Home | Tech Blog / 技术博客 | Essays | Photography | About.
- Only _tech and _essays article collections; technical URLs /tech/:name/; no technical Category or type discriminator.
- Migrate both explicitly labeled Demo articles without losing bodies, dates, translations or changelog. Their former Demo URLs have no confirmed external references; no redirect system is required.
- Preserve Home Hero, Exploring (3 paragraphs per language), Beyond (6), thoughts collection, profile, Photography data and _essays contents.
- Technical Tags use build-time Unicode NFKC/casefold canonical keys; optional, multiple, inferred from posts; retain clear focus/selected styles and no nested links.
- Shareable ?tag= links, one selected Tag, All clears, popstate and language switch preserve state; unknown Tags and empty data show empty states.
- Remove RSS dependency/config/output/metadata/current manuals; retain sitemap and basic SEO, including publish/update dates.
- Inline decorative SVG with currentColor, 1em sizing, aria-hidden and focusable=false; never replace meaningful body symbols.

## Review focus

- Mixed-case / whitespace Tags and special URL characters resolve to one canonical key.
- No Tags, no posts and unknown Tag URLs remain usable.
- Modified-click links retain native new-tab behavior; Back/Forward restores filtering without reload.
- Optional missing translation and dates keep existing article behavior.
- Legacy paths/feeds stay absent from fresh build and sitemap; original article bodies remain byte-equivalent.
